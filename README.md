Design & Implementation
The website's design was guided by three key principles:
1.	Accessibility
2.	CRAP Principles (Contrast, Repetition, Alignment, Proximity)
3.	Mobile-First Design
Initially, I planned to use a grid layout, but Flexbox seemed more appropriate due to the limited number of main themes. However, as the project concept grew, I found that using both Flexbox and Grid components was the best solution.
•	Responsive Typography & Imagery: I used EM/REM measurements for text instead of pixels to maintain responsiveness. I tested different measurements and found that 1em worked best on mobile, scaling up for tablets and desktops after a bit of trial and error. All images are responsive, and I've added alt text to ensure accessible content.
•	User Experience: I set margins and padding to create space and contrast around all content. To enable the user to go through the work chronologically, I removed buttons that were dependent on chronological order. This ensures the next item a user sees is the next paragraph of the paper.
•	Buttons: I decided to make them card "buttons" after some research. The image backgrounds were added for visual impact and contextual clues. I made them 100px in height to give them a "boxy" look for mobile display and kept the rounded edges for visual appeal.
